# Week 1 – C

Welcome to my **Week 1** projects for **Harvard's CS50x: Introduction to Computer Science**.

Week 1 marks the transition from Scratch's visual programming environment to writing real programs in **C**. Throughout this week, I explored the fundamentals of procedural programming by learning how to write, compile, debug, and execute C programs while developing stronger algorithmic thinking and problem-solving skills.

Completing these projects significantly strengthened my understanding of how software behaves at a lower level, laying the foundation for future topics such as memory management, data structures, and systems programming.

## Projects

| Project | Description | Status |
|---------|-------------|:------:|
| [World](./world/) | A simple "Hello, World" program introducing compilation and program execution in C. | ✅ |
| [Me](./me/) | My first interactive C program that prompts for the user's name and prints a personalized greeting. | ✅ |
| [Mario (Less)](./mario-less/) | Generate a right-aligned pyramid using loops and nested iteration. | ✅ |
| [Mario (More)](./mario-more/) | Build two side-by-side pyramids using nested loops and formatted output. | ✅ |
