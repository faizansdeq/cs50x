# Week 0 – Scratch

Welcome to my **Week 0** projects for **Harvard's CS50x: Introduction to Computer Science**.

Week 0 introduces computational thinking through Scratch, a visual programming language. Although Harvard's CS50x requires only a single Scratch project for Week 0, I developed **five independent projects** to deepen my understanding of computational thinking, game development, event-driven programming, and problem-solving before transitioning to C.

This week strengthened my understanding of computational thinking and laid a strong foundation for learning text-based programming in C throughout the remainder of CS50x.

---

Assessment source and submission artifacts are kept private; see [Source Code & Academic Honesty](../README.md#source-code--academic-honesty).

## Projects

| Project | Description |
|---------|-------------|
| [AI Pac-Man](./pac-man/) | A Pac-Man-inspired game featuring AI-controlled ghosts, power pills, score tracking, lives, and multiple levels. **(Official CS50 Submission)** |
| [Flappy Bird](./flappy-bird/) | A recreation of Flappy Bird focusing on gravity, collision detection, obstacle generation, and score tracking. |
| [Shoot the Monster](./shoot-the-monster/) | An action game featuring multiple levels, enemy interaction, and progressively increasing difficulty. |
| [Pong](./pong/) | A recreation of the classic Pong game demonstrating collision handling, paddle mechanics, and score tracking. |
| [Paint](./paint/) | A simple drawing application allowing users to create artwork using multiple colors. |

## Programming Concepts Explored

Throughout these projects, I explored and practiced:

- Event-driven programming
- Variables and lists
- Conditional logic
- Loops
- Broadcast messages
- Cloning
- Collision detection
- Game state management
- Animation
- User input handling
- Basic AI behavior
- Debugging and iterative development

---

## Learning Objectives

During Week 0, I focused on:

- Breaking complex problems into smaller, manageable components
- Designing algorithms visually before writing traditional code
- Managing game state and object interactions
- Building interactive applications using event-driven programming
- Developing systematic debugging and problem-solving skills
